# 数据盘

本页管 FAT 数据盘编辑和恢复；编辑前先在被控电脑安全弹出，重要数据先快照。
导航：[操作约束](#操作约束) · [失败与恢复](#失败与恢复) · [源码](#源码)。返回[开发导航](../README.md#开发导航)。

## 操作约束

挂载时只可浏览和下载文件，内容可能落后于主机缓存；只读挂载也不能编辑。
完整镜像下载在可写挂载时拒绝。维护和删除要求确认盘名，格式化可先快照，快照失败则不格式化。
扩容只支持无分区表的 FAT 数据盘，准备新镜像并检查后替换；需同时容纳新镜像和旧盘快照。
快照不自动淘汰；删除盘可保留快照，重建同名盘后恢复会连同容量一起还原。

文件操作只提供同目录重命名：mtools 跨目录移动曾损坏名称或崩溃。
FAT 名称不区分大小写；长名转小写短名可能以大写保存，内容不变。
本页数据盘时间按 UTC 解读；NAS 文件夹卷的时间规则见[网络存储](storage.md#nas-文件夹-u-盘)。

## 失败与恢复

编辑只持该盘锁，其他盘和状态读取不应被阻塞；编辑中的盘不能挂载。
客户端断开取消上传和下载。上传在导入前取消不改镜像，导入和格式化中断不保证回滚。
快照仅完成后发布，恢复和扩容准备失败保留原盘。
强制结束可能留下占空间的隐藏临时文件，不会把半成品列为可恢复快照。
