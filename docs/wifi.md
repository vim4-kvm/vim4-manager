# Wi-Fi 管理与热点

本页管网络页的无线入口；切换模式可能断开正在使用的会话。
导航：[模式](#模式) · [回退](#回退) · [源码与验证](#源码与验证)。返回[开发导航](../README.md#开发导航)。

## 模式

客户端与热点互斥，总开关关闭两者，有线网络不受影响。
使用 NetworkManager 持久配置；热点提供共享网络，不另起 hostapd。
热点不是开放网络，首次未设密码由助手生成；二维码与显示密码同样暴露凭据，二维码本地生成。
频段、信道、主接口选择和地址查 helper 的 wifi_*，不要假定每块板的接口名相同。
客户端扫描按 SSID 合并强信号；隐藏网络和扫描失败时可手动输入。

## 回退

客户端切热点失败时恢复原连接。
热点切客户端时可等待已保存网络，失败恢复热点；强制切换表示明确接受断连。
网页是否使用回退取决于请求是否经过无线及是否有保存网络，经有线可直接切换后扫描。
连接新网络失败删除本次新建连接，保留已有同名配置，并恢复先前连接或热点。
WPA3-only 先检查实际接口能力；固件声明 SAE 不足以证明内核和 supplicant 可用，失败不能破坏原入口。

## 源码与验证

接口查 [web.go](../internal/web/web.go)，参数及超时查 [helper](../deploy/vim4-manager-helper) 的 wifi_command、wifi_change_mode、wifi_apply_profile。
密码仅经 stdin，不进参数或日志。认证规则统一见[账户](auth.md#账户)，tailnet 登录后可写。
状态和扫描不占写操作锁，连接及切换串行执行。
[浏览器回归](../web/tests/wifi.mjs)使用模拟 API，不改变真实无线。
真实验证经有线访问，检查热点 AP 状态、客户端连接及失败回退；离线通过不能替代实机关联。
